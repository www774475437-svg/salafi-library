# مكتبة العلماء السلفية

كتب شيخ الإسلام ابن تيمية، وابن القيم، وابن رجب، وابن باز، والألباني، وابن عثيمين، ومقبل الوادعي، وصالح الفوزان، من مكتبة «تراث»:
قراءة، وتحميل للقراءة بلا إنترنت، وبحث، وتظليل بثلاثة ألوان، واقتباس مع المصدر، وفواصل.

- الموقع: https://www774475437-svg.github.io/salafi-library/
- تطبيق أندرويد: https://github.com/www774475437-svg/salafi-library/releases/latest/download/salafi-library.apk

يُبنى التطبيق والموقع تلقائيًا على GitHub Actions مع كل تحديث (`.github/workflows/main.yml`).
فهرس الكتب يُصنع عند كل بناء من «تراث» (`tool/build_catalog.py`).
